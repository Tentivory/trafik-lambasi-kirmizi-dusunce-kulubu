# Trafik Lambası Kırmızı Düşünce Kulübü

Resmi adı: **Kırmızı Işıkta Düşünme Zorunluluğu ve Yeşilde Unutma Protokolü**  
Kurum kodu: `ISO/TR-KIRMIZI-472`  
Ciddiyet seviyesi: aşırı. Komiklik seviyesi: sıfır. (Yalan.)

Bu depo, kavşakta kırmızı yandığında beynin boşa çalışmasını engellemek için kurulmuş ulusal bir düşünce kulübüdür. Yeşil yanınca düşünce iptal edilir, çünkü arkadaki korna felsefe kabul etmez.

## Ne işe yarar

`python kirmizi_dusunce.py` çalıştırılınca:

1. Sana kaç saniye kırmızı olduğunu sorar.
2. O süreye göre bir düşünce derecesi biçer (hafif dalga, orta varoluş, ağır kırmızı).
3. Rastgele ama tutarlı bir kulüp üyelik cümlesi üretir.
4. Yeşil yanınca düşünceyi çöpe atar ve korna raporu yazar.
5. Çıktıyı `tutanak.txt` dosyasına işler. Evet, gerçekten.

Argümansız çalışırsa 17 saniyelik demo yapar. Bu süre, bir Türkiye kavşağında "acaba geçsem mi" diye düşünmenin yasal üst sınırıdır. Sınır biz uydurduk. Sınır artık sınırdır.

## Kurulum

```bash
git clone https://github.com/Tentivory/trafik-lambasi-kirmizi-dusunce-kulubu
cd trafik-lambasi-kirmizi-dusunce-kulubu
python kirmizi_dusunce.py
python kirmizi_dusunce.py --saniye 42 --isim "Muavin"
```

Bağımlılık yok. Python 3 yeter. Kavşak şart değil ama tavsiye edilir.

## Üyelik dereceleri

| Saniye | Derece | Hak |
| --- | --- | --- |
| 0-8 | Sarı tereddüt | Tek cümle |
| 9-25 | Kırmızı üye | Bir pişmanlık |
| 26-60 | Uzun kırmızı | Hayatı sorgulama |
| 61+ | Lambayı bekleyen | Artık yaya sayılırsın |
